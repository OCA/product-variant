1. Select the source templates in the product list (or the variants to move
   in the product variant list) and choose *Actions > Move Variants to
   Template*.
2. Choose the target template. Each variant gets a line with the attribute
   values it will have in the target, prefilled with its current values and
   with the attributes the target only allows with a single value.
3. Adjust the values of each line. Every variant needs one value for each
   attribute of the target, plus any attribute you add.
4. If the variants bring attributes the target does not have yet, choose the
   value the existing target variants take for them.
5. Review the preview: blocking problems, warnings (price changes, template
   fields the variants will inherit, target records that will now also apply
   to them) and the list of changes. Then click *Move Variants*.

Unarchiving a source template left without variants makes Odoo create new
variants for it from its attributes, as for any template without variants.
