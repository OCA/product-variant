This module allows to display product variant sale price based on a base
pricelist.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

If users manage their variant prices through pricelists and fixed prices
on them, the list price displayed on the variant form and list is not
correct as computed on product template price.

So, the idea is to compute a new field based on the base pricelist
defined on the company level.

Configuration
=============

- Go to Sale > Configuration > Pricing
- Select the default pricelist to display the product variants display
  price.
